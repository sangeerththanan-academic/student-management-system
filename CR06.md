# CR06: Dashboard Sidebar & Course Management Implementation Plan

## Objective
Introduce a sidebar navigation (Dashboard Bar) to the Admin Dashboard to allow switching between different management modules. Add a new "Courses" module that includes an interface for administrators to create and manage courses.

## 1. Frontend Layout Refactoring
Currently, `DashboardPage.jsx` directly renders the student list. We need to refactor it to act as a layout wrapper containing the sidebar and an outlet for the active module.

### Subtasks:
- **Update Routing (`frontend/src/routes/AppRoutes.jsx`)**:
  - Change the `/dashboard` route to render a layout component.
  - Add nested routes for `/dashboard/students` (default) and `/dashboard/courses`.
- **Create Sidebar Component (`frontend/src/components/DashboardSidebar.jsx`)**:
  - Implement a sidebar with navigation links to "Students" and "Courses".
  - Include styling (`dashboard-sidebar.css`) for active states and layout.
- **Refactor `DashboardPage.jsx`**:
  - Move the specific "Students" logic (fetching students, search, table) into a new component, e.g., `frontend/src/pages/admin/StudentsView.jsx`.
  - Update `DashboardPage.jsx` to render the `DashboardSidebar`, the header, and an `<Outlet />` (from `react-router-dom`) for the main content area.

## 2. Courses Module (Frontend)
Create the new interface for managing courses.

### Subtasks:
- **Create `CoursesView.jsx` (`frontend/src/pages/admin/CoursesView.jsx`)**:
  - Implement the UI for the "Courses" section, similar to the Students section (heading, "Add Course" button, empty state, and list/table of courses).
- **Create `CourseFormModal.jsx` (`frontend/src/components/CourseFormModal.jsx`)**:
  - Implement a modal containing a form to create a new course.
  - Fields needed (example): `Course Code`, `Course Name`, `Description`, `Credits`.
  - Add form validation and submission logic pointing to the API (e.g., `POST /api/courses`).
- **Create API Service**: Add course-related functions in `frontend/src/services/api.js` (or a dedicated `courseService.js`).

## 3. Backend Implementation (Prerequisites for Frontend)
To support the new frontend interface, the backend needs to handle course data.

### Subtasks:
- **Database Schema (`database/schema.sql`)**:
  - Add a `courses` table.
- **Course Routes (`backend/src/routes/courseRoutes.js`)**:
  - Implement `POST /api/courses` (Create), `GET /api/courses` (List).
- **Course Controller (`backend/src/controllers/courseController.js`)**:
  - Implement the logic to interact with the database for course creation and retrieval.
- **App Update (`backend/src/app.js`)**:
  - Register the new course routes.

## 4. Execution Steps
1. **Step 1:** Implement the backend database changes, routes, and controllers so the frontend has an API to talk to.
2. **Step 2:** Create the `DashboardSidebar` component and update `DashboardPage.jsx` CSS to accommodate a side-by-side layout (e.g., using CSS Grid or Flexbox).
3. **Step 3:** Refactor existing student logic into `StudentsView.jsx` and set up nested routing.
4. **Step 4:** Build `CoursesView.jsx` and `CourseFormModal.jsx`.
5. **Step 5:** Connect the course forms to the backend API and verify functionality.
